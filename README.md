# Automation Lab 6

## Описание проекта

Данный репозиторий создан для выполнения лабораторной работы № 6 по изучению Git и GitHub.

## Цели работы

- Создание репозитория на GitHub.
- Работа с файлами проекта.
- Изучение истории коммитов.
- Создание и использование веток.
- Изучение Pull Request.

## Структура проекта

- `README.md` — описание проекта.
- `requirements.txt` — список зависимостей Python.
- `.gitignore` — список файлов и папок, которые Git не должен отслеживать.

## Технологии

- Git
- GitHub
- Python
